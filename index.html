Riwayat Pembaruan

v0.1.2 | 06 November 2026 (Terbaru)
  • Laporan Gabungan per Gudang: Rekapitulasi otomatis data opname fisik seluruh petugas cek berdasarkan gudang aktif.
  • Filter Kolom per Lokasi Rak: Pengelompokan dinamis header petugas & rak tanpa akumulasi duplikasi ganda Qty per barang.
  • Kalkulasi Selisih & Status: Perhitungan otomatis nilai selisih terhadap Stok Bosnet (K Akhir) beserta status SESUAI, SELISIH LEBIH, atau SELISIH KURANG.
  • Arsip Laporan Pertanggal: Dropdown peninjauan kembali riwayat stok opname berdasarkan tanggal penyelesaian SO.
  • Export Rekapitulasi Excel: Fitur unduh file spreadsheet .xlsx lengkap dengan rincian kolom kelompok petugas, selisih, dan status.
  • Fitur Hapus Data SO: Penambahan tombol hapus data pada modal edit hasil cek fisik (silang merah) untuk mengoreksi kesalahan input.
  • Manajemen Database Lokal: Menu baru di Setelan untuk memantau status penyimpanan Database Lokal & opsi pembersihan cache secara aman.
v0.1.0 | 05 November 2026
  • Struktur Gudang Dinamis: Pengaturan otomatis folder gudang (WH-1, WH-2, WH-3, dan Blok khusus).
  • Filter Master Excel Bosnet: Validasi kolom Produk, Nama, Lokasi, serta mengabaikan baris dengan nilai K Akhir 0/0/0/0.
  • Offline-First & IndexedDB: Penyimpanan catatan lokal dan sinkronisasi manual ke Firebase RTDB pada halaman Lihat.
  • Master Data Autocomplete: Fitur download master data dari server untuk acuan pencarian kode barang.
